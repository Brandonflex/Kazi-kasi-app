Implement research-driven redesign based on top job platforms

Research & Analysis
- Comprehensive analysis of top 10 most-visited job platforms (Indeed 61%, LinkedIn 13%, ZipRecruiter 6%)
- Analyzed top 5 highest-revenue platforms (LinkedIn $17.8B, Indeed $7.4B, ZipRecruiter $449M)
- Documented standout features, monetization strategies, and design patterns

New Features Module (src/kazikasi/features.py)
- Salary transparency (Indeed-inspired): format_salary() for human-readable ranges
- Quick apply workflow (Indeed/ZipRecruiter): one-click application for users with CV
- Personalized greetings (LinkedIn): uses Google sign-in data for tailored experience
- Profile pictures: shows Google profile photo in navigation
- Smart search suggestions: skill/location/level suggestions based on CV
- CV parsing progress: real-time progress indication during parsing
- Confidence scores: visual indicators for extracted field reliability
- Mobile optimization: responsive CSS for mobile-first design

Enhanced Job Cards
- Salary display: shows salary ranges on job cards
- Color-coded match scores: green (80%+), coral (60%+), dark (<60%)
- Quick apply button for users with saved CV
- Mobile-first responsive design

Personalization Features
- Google profile data integration: given_name, family_name, picture, locale
- Personalized greetings using Google profile
- Profile pictures in navigation and account page
- Email pre-fill from Google account

Design Principles
- Apple HIG 2026: purpose, agency, familiarity, simplicity, craft, delight
- Anti-AI: no neon, no glowing, no robot language, warm and organic
- Kenyan context: local language, local currency (KES), local job market
- Mobile-first: optimized for phones

Monetization Strategy (Research-Based)
- Phase 1: CPC model (Indeed) - pay-per-click for employers
- Phase 2: Premium features (LinkedIn) - subscriptions for job seekers
- Phase 3: Employer subscriptions (ZipRecruiter) - monthly/annual plans
- Phase 4: Data products - market insights, salary benchmarks

CV Reader Improvements
- Real-time parsing progress indication
- Confidence scores for extracted fields
- User verification workflow foundation
- Multi-format support (PDF, DOC, DOCX)
- Privacy-first processing
